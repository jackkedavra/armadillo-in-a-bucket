# Armadillo in a Bucket

Fabric-Mod für Minecraft 26.2. Rechtsklick mit einem leeren Eimer auf ein Gürteltier fängt es ein, Rechtsklick mit dem Eimer auf einen Block setzt es wieder ab. Name, Alter und alle anderen Daten bleiben erhalten.

Braucht Fabric Loader 0.19.3+ und Fabric API.

Gebaut wird automatisch über GitHub Actions (Tab "Actions", Artefakt "armadillo-in-a-bucket").
